# Etiquetas Tienda Pro 4.0.0

Primera distribución de escritorio en este repositorio para Windows x64.

- Gestión local de productos y precios.
- Importación/exportación del inventario y etiquetas térmicas de 80 mm.
- Actualizador configurado para futuras versiones publicadas en GitHub Releases.

Descarga el archivo `Etiquetas-Tienda-Pro-4.0.0-x64.exe` y sigue el instalador.
Los archivos “Source code” son para desarrollo.

Antes de actualizar, exporta tu inventario. Instalador sin firma digital salvo
que el responsable añada una antes de compilar. Condiciones de uso propietarias.
